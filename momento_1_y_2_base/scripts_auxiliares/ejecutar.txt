=============================================================================
CÓMO EJECUTAR EL PROYECTO (MODELO CNN DE 19 CLASES DE RESIDUOS)
=============================================================================

1. APLICACIÓN WEB DE CLASIFICACIÓN (19 CLASES):
   Abre una terminal en esta carpeta y ejecuta:
   
   ./.venv/bin/python app_19clases.py
   
   Luego abre tu navegador en: 👉 http://127.0.0.1:7860

2. DEPURADOR VISUAL DE DATASET (GRADIO):
   Para revisar y descartar imágenes interactivamente con 1 clic:
   
   ./.venv/bin/python depurador_visual.py
   
   Luego abre tu navegador en: 👉 http://127.0.0.1:7862

3. VERIFICADOR DEL ESTADO DEL DATASET (CLI):
   Para consultar el conteo actual de fotos limpias por categoría:
   
   ./.venv/bin/python verificar_dataset.py

4. CUADERNOS JUPYTER DE LA PRESENTACIÓN:
   - 1_Pipeline_Dataset_10k_Imagenes.ipynb (Descarga masiva, limpieza y estandarización)
   - 2_Entrenamiento_Modelo_19Clases.ipynb (Entrenamiento, métricas y evaluación del modelo)
   - modeloCNN_9clases_base.ipynb (Cuaderno base original de las 9 clases iniciales)

5. APLICACIÓN WEB HISTÓRICA (9 CLASES BASE):
   ./.venv/bin/python app_9clases_base.py
